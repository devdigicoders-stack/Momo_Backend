# Momos Bhandar - Backend

Restaurant Management & Business Control System (Phase 1)

## Tech Stack
- Node.js & Express.js
- MongoDB & Mongoose
- JWT Authentication
- bcryptjs for password hashing

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Configure environment:
Check `.env` file for MongoDB connection string and JWT Secret.

3. Start development server:
```bash
npm run dev
```

The database automatically seeds the initial Super Admin on first run:
- Mobile: `9999999999`
- Password: `Admin@123`
- Role: `SUPER_ADMIN`
